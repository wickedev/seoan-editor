# official-nk630

통합명세서작성기(NK-Editor 6.30, 2025-10-01)가 Wine에서 만든 실물 출력.
원고는 공개해도 되는 시험 문서(문서 처리 방법)이고, 도면은 블록도 1장이다.

| 원고 | 공식 출력 | 내용 |
|---|---|---|
| `t2.txt` | `t2.official.hlz` · `.fin` | 도면 없음, 청구항 1 |
| `t3.txt` | `t3.official.hlz` · `.fin` | 도 1(300dpi 1비트 G4 TIFF), 도면의 간단한 설명, 부호의 설명, 대표도 |

공식 작성기에 넣은 방법: 신규 특허 명세서등(국어) 서식 → 본문 전체를 원고로 교체(붙여넣기) →
【도 1】 다음 줄에 이미지 삽입 → 제출파일 생성. `documentID`는 시각 기반이라 비교에서 뺀다.
